# ด็อกจด 🐶

ถ่ายหรือแชร์สลิปโอนเงิน → แอปอ่านข้อมูลด้วย Gemini → จดลง Google Sheets ให้เอง (Android เท่านั้น)

## ติดตั้ง

1. เปิดหน้า [Releases ล่าสุด](https://github.com/NatthawutSK/dog-jod-releases/releases/latest) แล้วกดไฟล์ `dog-jod-vX.Y.Z.apk` เพื่อดาวน์โหลด
2. เปิดไฟล์ที่ดาวน์โหลดมา ถ้าเครื่องเตือน ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์หรือแอปจัดการไฟล์
3. กดติดตั้ง แล้วเปิดแอป

**อัปเดต:** แอปเช็กเวอร์ชันใหม่วันละครั้ง ถ้ามีจะขึ้นแบนเนอร์ กดดาวน์โหลดแล้วติดตั้งทับได้เลย ข้อมูลไม่หาย

## ตั้งค่าครั้งแรก

1. **ล็อกอินด้วย Google** แอปเห็นเฉพาะไฟล์ที่แอปสร้างเอง
2. **วาง Gemini API key** สร้างฟรีได้ที่ <https://aistudio.google.com/apikey> (คีย์ฟรี Google อาจนำสลิปไปใช้เทรนโมเดล)
3. **ชีต** แอปจะหาชีต "ด็อกจด" ที่เคยสร้างไว้ หรือสร้างใหม่ให้ (มีแท็บ `รายจ่าย` และ `หมวดหมู่`)

## วิธีจด

- **แชร์รูปสลิป** จากแอปธนาคารเข้าด็อกจด หรือ**เลือกรูป**หลายใบในแอป
- **จดอัตโนมัติ** เลือกโฟลเดอร์สลิปในเครื่อง รูปใหม่ในโฟลเดอร์จะถูกจดเอง (ต้องให้สิทธิ์อ่านรูปทั้งหมด และตั้งแบตเตอรี่ของแอปเป็น Unrestricted) รูปที่จดไม่ได้จะไปอยู่ใน "สลิปพลาด" กดลองใหม่หรือทิ้งได้
- **ใบแจ้งยอดบัตรเครดิต** (PDF ที่มีรหัส) เลือกในแอปได้ ทุกรายการซื้อจะจดแยกแถว
- ไม่มีเน็ตก็ใช้ได้ แอปจะรอแล้วจดต่อเองเมื่อกลับมาออนไลน์
